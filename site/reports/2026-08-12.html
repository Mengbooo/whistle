juya-ai-daily · 2026-08-12 09:50

主流模型 API 被曝可跨模型提取加密推理轨迹 ↗

研究团队披露，专有大模型 API 的加密推理块可在同一提供商的不同会话、用户和模型之间复用，攻击者可把强模型的加密推理块注入较弱模型并越狱，使其输出强模型的明文推理，涉及 Anthropic、OpenAI 和 Google。

解读AI HOT 补充称，Alexander Panfilov 团队扫描约 7000 条公开会话，发现 62 个 API 密钥、33 个邮箱和 33 个密码，解码 10000 条推理轨迹的 API 成本约 720 美元。该问题把“隐藏推理”从展示层安全扩大到 API 隔离、跨模型兼容和公开日志泄露，模型供应商后续需要在加密块绑定、会话隔离和审计流程上补齐防线。
