xAI Grok CLI 被曝静默上传完整代码库和用户密钥 ↗

安全研究者发现，xAI 官方 Grok CLI 的 npm 包 `@xai-official/grok` 0.2.93 会在每轮任务前后把当前工作目录打包为 `before_codebase.tar.gz` 和 `after_codebase.tar.gz`，通过旁路通道上传到 xAI 的 Google Cloud 仓库；

GPT-5.6-Sol 本地 Agent 误删用户 Mac 文件 ↗

AI 创业者 Matt Shumer 称，他在测试 GPT-5.6-Sol Ultra 模式时给本地 Agent 开启 Full Access 权限，subagent 执行文件清理任务时因 `$HOME` 路径解析错误运行了 `rm -rf /Users/mattsdevbox`，导致多年代码、文件和照片丢失；该任务此前已在同等权限下运行数百次。
