今日头条

DeepSeek 开源 DSpark，推理加速成为模型成本竞争的前台问题

DeepSeek 发布 DSpark 投机解码框架，配套开源 DeepSpec 训练与评估代码、DeepSeek-V4-Flash 和 V4-Pro 的 DSpark checkpoint。它不是新模型，而是在 DeepSeek-V4 上附加草稿模块，通过半自回归生成和动态校验提升单用户生成速度；论文称相对生产基线 MTP-1，V4-Flash 提升 60% 到 85%，V4-Pro 提升 57% 到 78%。这对产品和平台团队的启发很直接：当模型能力差距缩小时，吞吐、延迟、单位 token 成本和可复现部署会成为体验与毛利的关键变量。

OpenAI 预览 GPT-5.6 Sol，高能力模型进入受控准入叙事

OpenAI 发布 GPT-5.6 Sol 预览，HN 上相关讨论获得超过千分，AI HOT 同时记录了美国政府要求 OpenAI 暂缓广泛发布、先向少数合作伙伴提供受控预览的报道。即使具体能力细节尚未充分披露，这件事也说明前沿模型发布正在从“公布即开放”转向更复杂的安全评估、客户准入和监管协商。依赖最强模型的团队应准备降级路径、模型替代和敏感任务隔离，不要把核心业务流程绑定在尚未稳定开放的单一模型上。

Codex 优化长线程、跳转和 Markdown 复制，开发 Agent 开始补齐日常使用细节

OpenAI Developers 介绍了 Codex 应用过去一周的体验优化，包括长线程位置保持、边缘导航栏跳转、设置搜索、缩放定位、线程切换减负，以及复制到 Slack 时保留 Markdown 格式。它不是轰动式发布，但对高频用户很关键：Agent 的生产力不只来自模型能力，也来自长任务回看、上下文定位和跨工具转移。编码 Agent 若要成为团队基础工具，下一阶段会继续从原始文本输出演进到 Markdown、HTML 甚至更结构化、可交互的工作界面。

阿里千问输入法上线 macOS，AI 语音输入从应用功能变成系统入口

阿里千问输入法 macOS 版已开放下载，官方称支持最快 300 字/分的 AI 语音输入、自动润色、口语转工整文字、中英混说和 9 种方言，并预告 iOS、Android、Windows 版将于近日发布。输入法是比聊天应用更底层的入口，因为它贴近所有文本生产场景。值得关注的是，人类常用音频输入，但 AI 输出会越来越视觉化、结构化、可编辑；输入法类产品如果只做语音转文字还不够，未来竞争会落在上下文理解、格式化和跨应用工作流上。

Weave 推出本地模型路由，可接入 Claude Code、Codex 和 Cursor

Weave 发布智能模型路由工具，可通过 npx @workweave/router 安装并作为本地代理运行，兼容 Anthropic、OpenAI、Gemini 原生 API，也可经 OpenRouter 接入 DeepSeek、Kimi、GLM、Qwen、Llama、Mistral 等模型。它把模型选择从配置文件推进到每次请求现场，并支持本地密钥存储、OTLP 追踪和自托管。对团队来说，这类工具的价值在于降低多模型试验门槛，但真正上线前仍要验证路由依据、失败回退、日志隐私和供应商账单控制。

Runway API 将广告本地化做成 Recipe，开发者可通过一次 API 调用翻译静态广告和图形资产。它的信号不在于“又多一个翻译工具”，而在于生成式视觉平台开始把模型能力包装成营销团队能直接调用的流程单元。增长和本地化团队可以试验它在多市场素材变体上的效率，但仍应保留品牌审校、法规敏感词检查和投放渠道格式校验。

OpenKnowledge 试图把本地 Markdown 知识库变成 Agent 原生工作台

OpenKnowledge 是开源、本地优先的 Markdown 编辑器，支持桌面和 Web UI、文件导航、搜索、标签、图谱 wiki 链接、MCP、CLI、技能和智能搜索，可与 Claude、Codex、Cursor 等工具协同编辑。它说明知识库产品正在分化：一类继续做协作文档，另一类把本地文件、Git、AI Agent 和结构化知识图谱放在同一工作空间。对个人和小团队来说，这类工具适合作为可迁移的知识底座，但要评估数据格式、同步冲突和插件权限。

今日行动建议

  • 产品：检查 AI 功能是否仍停留在聊天框；高频场景应补任务状态、引用来源、审批、回滚和格式化输出。
  • 研发：为编码 Agent 建立真实仓库评测集，限制网络和 Git 历史访问，记录命令、文件变更、失败与越权行为。
  • 运营：把 Runway、千问输入法等工具用于素材和文本生产试点，但保留品牌审校、版本记录和投放渠道校验。
  • 安全：对陌生仓库、招聘测试和开源 patch 建立隔离运行规范，优先审查安装脚本、补丁文件和凭据访问。
  • 管理者：盘点 ChatGPT、Claude、Codex、Cursor 等工具的账号、订阅、额度和替代路径，避免关键工作被单点故障打断。
  • 创业者：关注模型路由、推理加速、垂直 Agent 和再培训项目，但优先选择有数据闭环、权限边界和明确付费方的场景。
