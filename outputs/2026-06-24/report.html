今日头条

Anthropic 推出 Claude Tag，让 Claude 以独立身份进入 Slack 协作

Anthropic 发布 Claude Tag，企业和团队用户可以在 Slack 频道中通过 @Claude 委托任务，Claude 能读取授权频道上下文、跨数据源学习，并在开启环境行为后主动回到未解决线程。更值得关注的是配套的 agent identity 访问模型：Claude 不再伪装成某个员工，而是以可配置、可审计、可限权的智能体身份工作。对团队来说，这会把 Agent 从个人 IDE 和聊天窗口推向共享工作流，下一步竞争重点不是“能不能回答”，而是权限边界、上下文治理和长期任务交接是否可靠。

协作 Agent来源：Anthropic Newsroom、Claude Blog、HN 232 分

Seed2.1、豆包专业版与豆包音频模型集中更新，字节继续把 AI 推向生产力场景

字节 Seed 发布 Seed2.1 系列，强调通用 Agent、代码工程交付与多模态理解，并已在豆包、TRAE 和火山方舟 API 上线；同日素材中还出现豆包专业版与 Doubao-Seed-Audio 1.0，后者可用单条 Prompt 编排多角色对白、情绪、背景音乐和环境氛围。对产品和研发团队来说，字节的节奏说明国内大模型竞争正在从模型榜单转向办公、开发、内容生产和 API 商业化的闭环落地，值得跟踪其在真实工作流中的调用成本、稳定性和生态绑定方式。

平台化来源：字节 Seed、火山引擎、豆包

Mistral OCR 4 与百度 Unlimited OCR 同时升温，文档智能进入结构化竞争

Mistral 发布 OCR 4，支持边界框、块分类、逐页逐词置信度、170 种语言和自托管部署；百度 Unlimited OCR 则因“一次性长时域解析”在 HN 获得高分讨论。OCR 不再只是把图片转成文字，而是在向表格、签名、公式、版面和置信度这样的结构化输出演进。对知识库、财务、法务和内部流程自动化团队来说，短期行动是重新评估现有 OCR 链路是否能输出可追责的结构，而不是只看识别率。

文档智能来源：Mistral AI、百度 Unlimited OCR、HN 430/438 分

加州 AI 透明度法案引发开源许可冲突，GitHub 与开源联盟要求修正

GitHub 联合 Black Forest Labs、Hugging Face 和 Mozilla 呼吁修改加州 AI 透明度法案相关条款，原因是草案要求开发者在下游用户违规时撤销开源许可证，这与开源许可证通常不可撤销的原则冲突。这个事件不只是美国州法争议，它提示开源 AI 项目的合规责任正在向分发链条下游延伸。做模型、插件、Agent 框架和数据集的团队，应提前准备透明度文档、使用说明和下游责任划分，避免把合规问题压到发布当天处理。

开源合规来源：GitHub Blog

AI 与新工具

京东开源 JoyAI-VL-Interaction，视频智能体从问答走向实时观察

京东 JoyAI 开源 JoyAI-VL-Interaction，模型能持续观察视频流、判断关键事件并实时响应，还支持把复杂任务委托给后台 Agent。它面向摄像头、直播流、语音交互和长期记忆场景，适合安防、老人看护、直播讲解等需要“边看边说”的任务。这个方向比普通视频理解更接近环境感知型 Agent，长期看 AI 输出形态会继续从原始文本走向 Markdown、HTML 和可交互视觉界面，实时视频场景会推动输出从描述转向可操作状态面板。

实时多模态来源：京东 JoyAI

FastWan-QAD 在单卡 RTX 5090 上 1.8 秒生成 5 秒视频

Sky Computing Lab 发布 FastWan-QAD 视频生成模型系列，基于 FastVideo 的量化感知蒸馏方案训练，声称单张 RTX 5090 端到端生成 5 秒 480P 视频只需 1.8 秒，并开源模型、代码和博客。对内容工具和本地创作工作流来说，这类进展的意义在于视频生成的交互延迟可能从“等待渲染”压到“试错编辑”。如果质量稳定，产品形态会更像实时画布和可回滚时间线，而不是单次 Prompt 生成器。

视频生成来源：Sky Computing Lab

IBM 开源 CUGA，强调轻量 Agent 框架与可复制样例

IBM Research 在 Hugging Face 发布 CUGA，一个处理规划、执行循环、工具调用和状态管理的轻量级智能体框架，开发者提供工具列表和提示词即可构建 CugaAgent。它支持 OpenAPI、MCP、LangChain 函数和多模型提供商，并附带二十多个单文件示例应用。相比大而全平台，CUGA 的信号在于 Agent 框架正在回到“能被工程团队快速读懂和改造”的形态，适合作为内部原型和评估基线。

Agent 框架来源：Hugging Face Blog

网易有道 Confucius4-TTS 开源，3 秒音频支持 14 语种跨语种克隆

网易有道推出 Confucius4-TTS，称用户只需 3 秒音频即可完成零样本音色克隆，并支持 14 种语言跨语种无口音迁移、情感克隆和 Apache 协议开源。对内容、本地化、教育和客服团队来说，语音克隆的门槛继续下降，机会与风险会同时增加：一方面小团队能做多语种音频产品，另一方面声音授权、标注和反冒用机制必须提前设计进流程。

语音合成来源：IT之家

Runway 宣布推出 Seedance 4K、Seedance Mini 和 Kling 3.0 Turbo，并以“全球最佳模型汇聚一处”的方式进行产品化包装。这说明视频生成产品的竞争并不只在自研模型，而在于把多模型能力、计费、工作流和创作体验放在同一界面中。对视频团队来说，接下来评估工具时应看模型切换、素材管理和后期衔接效率，而不是只比较单次生成效果。

政策监管与合规

五眼联盟网络安全部门警告，自动化智能体会降低复杂攻击代码编写门槛，持续扫描漏洞并缩短防御窗口，AI 驱动的个性化钓鱼也在扩散。对企业安全团队来说，这不是抽象威胁，而是要求把 MFA、闲置账户清理、自动化监测和员工反钓鱼训练提到更高优先级。面向普通用户的互联网产品，也应重新审视账号恢复、异常登录和敏感操作确认流程。

产品
