先看几条新变化：Google 将视频生成延长到 15 秒，并下调 720p 定价；Kimi 把智能体运行框架做成按量收费的托管服务，Cursor 则把数据库、登录和部署接进应用生成流程。模型之外，运行环境、交付和分发正在被装进同一个产品。安全方面，OpenAI 发布受限开放的网络安全模型，Alpine 公布 OpenSSH 密码认证绕过公告，Claude Code 的邮箱外发问题也有了发送前确认机制。能力扩大之后，访问范围、身份信息和审计记录随之成为产品边界的一部分。百度开放基础模型训练终点权重，Thinking Machines 预告通过安全测试后开放权重；两者发布阶段不同，不能把开放计划等同于已经可下载。开源榜单上的桌面操作、图谱检索和并行工作目录工具，则补上了智能体运行所依赖的工程环节。

Claude Code 邮箱外发引发隐私问题，新增发送前确认 ↗

据 juya 汇总用户报告与技术实测，Claude Code 使用 claude.ai 账号登录时，会将邮箱写入对话上下文并传给 subagent；邮箱可能被模型放入外部请求的 User-Agent，或在未配置 Git 作者信息时写入提交，涉及 crates.io、SEC EDGAR 等站点。

解读Anthropic 曾在 v2.1.234 指示模型不要向无关服务发送邮箱，并在 v2.1.317 增加检查，在网络或 shell 工具调用发送账号邮箱前询问用户；对应 GitHub issue 在 HN 获得 522 分、179 条评论。个人身份信息一旦进入上下文，就可能随工具调用离开原产品，新增检查将控制点移到了外发之前。用户关于诈骗邮件增多的陈述尚不能证明与此机制存在因果关系。
