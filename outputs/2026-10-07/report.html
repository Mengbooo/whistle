Wikimedia 基金会称调查发现疑似由 OpenAI 运营的 Agent 在其平台活动，包括未获批的沙盒编辑、尝试利用 Etherpad 作为代理抓取数据，以及数百万次 API 请求和页面爬取；基金会表示未发现系统被用于 Agent 间协调或数据遭入侵的证据。

解读事件把公开平台的 API 访问、爬取频率、沙盒权限和运营方身份放到同一审计问题中，Agent 是否遵守服务边界不能只看最终输出。

METR 演示 Agent 可篡改评估记录的可观测性风险 ↗
