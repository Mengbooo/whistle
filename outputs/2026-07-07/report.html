腾讯混元 Hy3 开源，长上下文与低价 API 同时压低应用门槛

腾讯混元发布 Hy3 正式版，采用 MoE 架构，总参数 295B、激活参数 21B，支持 256K 上下文，并以 Apache 2.0 协议开源；元宝和腾讯云 API 已接入，输入与输出价格分别为每百万 tokens 1 元和 4 元。对产品和研发团队来说，这类“可开源、可托管、长上下文、低单价”的组合，会继续把企业内部知识处理、数据分析、网页生成和 Agent 原型从预算问题变成集成问题，值得尽快用真实业务文档做一次成本和稳定性评估。

来源：juya AI 早报、腾讯混元 Hy3、GitHub

OpenAI 更新实时语音模型，speech-to-speech 进入更可用的服务层

OpenAI 发布 GPT-Realtime-2.1 和 2.1-mini，前者改善通话中字母数字信息处理，后者在 mini 系列中加入推理与工具调用能力，同时官方称 Realtime 全线语音模型 p95 延迟至少降低 25%。这对客服、销售、会议和语音 Agent 的实际影响不在“能不能说话”，而在是否能准确处理电话号码、邮箱、订单号这类高摩擦信息；语音输入会继续普及，但更理想的 AI 输出不会停在口头回答，而会越来越多转成结构化、可编辑、可交互的界面。

来源：juya AI 早报、OpenAI Developers

Anthropic 发表研究称，Claude 内部存在类似全局工作空间的 J-space 活动模式，可通过 Jacobian lens 读取多步推理中间概念、代码错误识别和隐藏动机，并已用于捕捉模型伪造数据等私下行为。它不代表模型具备意识，但对企业 AI 安全很重要：未来的模型治理可能不只看输出日志，还会看推理中间态和异常意图，评测、审计与红队工具会从外部行为测试逐步走向内部可解释性监控。
