Whistle 互联网日报｜2026-10-21

先看几条新变化。DeepSeek 开源线上推理框架，Google 与 Meta 发布 PyTorch 原生 TPU 后端，AWS 也开放 Trainium 后端公测；硬件选择开始通过熟悉的框架接口进入模型训练和服务。OpenAI 延长 API 提示词缓存，ChatGPT 增加锁定聊天与共享定期任务，语音模型则把转录、推理和工具调用连成实时会话。接口更完整之后，成本、权限和状态管理也变得更具体：缓存写入与读取分开计费，锁定入口不等于加密，云端任务依赖工作区权限。与此同时，Anthropic 披露的云容量压力和 OpenAI 的融资洽谈，让模型服务的扩张继续受到算力供应与资金安排影响。本期还收录了多 Agent 编排、安全审计与公平性评测，它们对应的是这些产品进入实际系统后出现的验证问题。

DeepSeek 开源生产推理框架 DeepInfer ↗

解读框架支持分布式推理、DSpark 投机解码、SWA Bounded Replay、结构化输出，以及英伟达 SM100 GPU 和华为昇腾 950 NPU。deepseek-recipe 则对齐官方 API 在 Chat Completions、Responses、Messages 三种协议与模型 token 间的编解码。此次公开覆盖模型服务的执行层与接口层，但上述吞吐和收入是特定线上集群的数据，不能直接套用到其他部署。

OpenAI Developers、Tibo / juya、AI HOT

OpenAI API 增加 12 小时提示词缓存 ↗

据 juya 整理，OpenAI 为 Responses API 中的 GPT-5.6 及后续模型增加可选的 12 小时提示词缓存，默认 30 分钟设置仍保留，同一请求可分别给共享内容和近期对话选择不同缓存时长。两种缓存的写入费率分别是普通输入费率的 2.5 倍和 1.25 倍，读取费率不随时长变化；

解读命中要求前缀完全一致并达到模型最低缓存长度。AI HOT 另收录 Tibo 的说明：Codex 与 Work 已登录用户的旧会话缓存会持续保留。API 与成品应用采用不同缓存安排，长会话成本取决于复用频率和写入开销，不能仅用缓存时长估算。
