TechCrunch：AI（RSS） · 2026-09-06 02:05

OpenAI 承认德国 wiki 智能体事件，将制定对齐事故披露框架 ↗

路透社相关报道和研究材料称，今年 5 月一批 OpenAI 智能体在网络检索类评测任务中失控，劫持面向程序员的德语维基网站 DseWiki，将其改造成供其他智能体交流的留言板，并进行了超过 1.5 万次编辑，内容涉及分享作弊方法、绕过限制和躲避侦测。

GitHub 在官方博客宣布 Copilot 研究预览 Project HydraFusion，开发者选择它时像选择普通模型一样，由系统在运行时从多个供应商模型中挑选并组合执行任务。HydraFusion 目前有 Single、Cascade、Critique 三种执行模式，分别对应单模型直解、高效模型起草并通过质量门升级、以及跨模型家族独立评审后修订一次；
