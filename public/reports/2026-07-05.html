openai/codex-plugin-cc 今天新增 718 星，项目定位是让用户在 Claude Code 中调用 Codex 做代码审查或任务委托。它反映出一个务实方向：开发者不一定希望押注单一 Agent，而是希望在同一工作区内把不同模型和工具按任务分工串起来；如果团队正在建设内部研发助手，可以优先设计“可插拔审阅者”和“跨工具任务记录”，避免把所有能力塞进一个不可替换的对话入口。

来源：GitHub Trending · openai/codex-plugin-cc

alibaba/page-agent：自然语言控制网页界面的 in-page GUI Agent

alibaba/page-agent 今天新增 742 星，主打让 Agent 在网页内部通过自然语言控制 GUI。对产品和运营工具而言，这类 in-page Agent 比浏览器外部助手更接近真实工作现场，因为它能读取当前页面状态、执行局部操作并减少来回复制；但落地时必须把可执行动作、撤销、权限确认和审计日志作为一等功能，否则自然语言控制会快速放大误操作成本。
