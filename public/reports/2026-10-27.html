GPT-6.1 Terra 发布：电脑操作模型降价，Codex 同步调整用量 ↗

OpenAI 发布侧重屏幕理解、跨应用电脑操作和自然写作的 GPT-6.1 Terra，向 ChatGPT Work、Codex 的 Plus、Pro、Enterprise 和 Edu 用户开放，API 模型名为 gpt-6.1-terra；每百万输入、缓存输入、输出 token 分别为 1、0.05、5 美元，标准价格比 GPT-5.6 Terra 低 50%。

解读公司称其中等推理强度的 Agents' Last Exam 成绩较上一代高 15 个百分点、与 GPT-6 Astra 相当，任务完成快 3 倍以上且每 token 价格约为 Astra 的十分之一；易诱发错误测试中，低推理强度错误率从 53.6% 降至 16.7%，最高强度为 4.3%，这些数字均来自厂商测试。Tibo 同时宣布 Codex 28 天改进计划第 21 天执行全量重置，第 22 天上线 Terra，称 API 和订阅提供的用量为 Sol 的两倍；OpenRouter 也已接入并标注 1.05M 上下文。降价与用量调整改变了持续电脑操作的调用成本，但这些基准成绩不等于任意软件任务都能可靠完成，官方仍把最复杂的编程和深度研究留给 Sol 或 Astra。

Compaction Smuggling 暴露推理痕迹，OpenAI 已于 10 月 23 日修复 ↗

Xint 研究人员披露 OpenAI API 的 Compaction Smuggling 漏洞：先让 gpt-5.6-sol 产生加密推理，再利用 /responses/compact 的 instructions 参数让压缩步骤保留推理，最后交给 gpt-4.1 或 gpt-4o 回显，整个过程涉及三次 API 调用。
