OpenAI 报告显示 Codex 正从开发工具变成跨部门工作入口

OpenAI 内部报告称，2025 年 8 月至 2026 年 6 月间，Codex 在多个部门取代 ChatGPT 成为主要工作工具，各部门输出 token 中 Codex 占比升至 99.8%，法律、财务、招聘等非研发团队也跨过使用过半拐点。这条信息的价值不在于单家公司使用量，而在于 Agent 工作流正在脱离“写代码助手”的窄定义，变成可接收目标、持续执行、产出可审阅结果的组织生产界面；团队评估 AI 工具时，应开始把任务拆解、审阅权限、日志留存和责任边界纳入采购与流程设计。

OpenRouter 推出 MCP 服务器，把模型选择放进编码智能体工作流

OpenRouter 发布 MCP 服务器，向 Claude Code、Codex CLI、Cursor 等客户端提供实时模型列表、基准、价格、端点和测试推理能力。它把“选哪个模型”从网页查询变成 Agent 可以调用的上下文工具，降低多模型路由和成本比较的摩擦；对开发团队来说，模型评估会越来越像依赖管理，未来的优势不只来自单一强模型，也来自能否在 IDE、CI 和任务运行时动态选择合适模型。

MCP来源：OpenRouter

Meta 员工警告 AI 内容审核部署过快，平台治理进入高自动化阶段

Meta 已用大语言模型替换约一半人工审核请求，并计划年底前将部分内容类型的 AI 审核比例提升至 90% 以上，内部员工担心误删、限流和监督不足。内容平台的成本压力会推动审核自动化继续前进，但它也会直接改变创作者申诉、品牌安全、广告投放和内容合规的执行方式；依赖平台分发的业务需要把误判、恢复路径和平台政策变更纳入运营预案。

平台治理来源：The Decoder

General Intuition 以 23 亿美元估值完成 3.2 亿美元融资，核心资产来自 Medal 平台积累的数亿小时游戏操作数据，目标是训练可迁移到虚拟环境和机器人的通用智能体。游戏数据带有连续决策、视觉反馈和精确动作标签，可能成为低成本获得“行动数据”的重要来源；对 AI 应用公司而言，未来壁垒会更多来自专有交互数据和可验证任务闭环，而不是只包装通用模型能力。

今日行动建议

产品

把 Agent 入口从聊天框扩展到任务、通知、审阅和定时简报，优先设计可暂停、可追溯、可重跑的状态。

研发

试用 OpenRouter MCP、Cursor SDK 或 Claude Code 新权限配置，建立模型选择、日志、审阅和 CI 接入的最小规范。

运营

用 Runway、Midjourney 草稿模式或自建素材技能做小批量创意测试，但把品牌一致性和投放归因保留为人工复核点。

设计

关注 Figma 画布从静态设计向代码、动画和工作流扩展，提前整理团队提示词、组件规则和设计系统说明。

管理者

评估 Agent 工具时优先问三件事：谁能授权、失败如何回滚、数据是否留存；这比单次演示效果更接近真实风险。
