Anthropic 恢复 Claude Fable 5 访问，模型能力与安全分类器被一起推到前台

Anthropic 重新向全球付费用户开放 Claude Fable 5，并重置 5 小时与每周速率限制，同时更新网络安全分类器以拦截特定越狱技术，短期内也承认部分无害编码和调试请求可能被误判。对依赖 Claude Code、Claude.ai 或 API 的团队来说，这不是单纯的模型恢复，而是提醒生产流程要同时评估能力、限额、误拒率和安全策略；关键链路需要准备模型回退、任务重试和人工复核机制。

来源：Anthropic、Claude Support、juya-ai-daily

Cloudflare 将默认拦截混合用途爬虫，AI 时代的内容访问开始走向授权和计费

Cloudflare 宣布从 2026 年 9 月中旬起，对新客户、现有客户新建站点和现有免费客户默认拦截抓取广告页面的混合用途爬虫，并推动搜索、AI 训练与 Agent 爬虫分离，同时探索从按次抓取计费转向按使用计费。内容站、开发者文档和数据服务需要尽快梳理哪些内容允许搜索、哪些允许 Agent 访问、哪些需要付费授权；长期看，网页内容会更像可授权资源，而不是默认被所有模型和爬虫免费吸收的公共输入。

来源：Cloudflare、Cloudflare AI options、juya-ai-daily、AI HOT

Microsoft 投入 25 亿美元派驻 6000 名 AI 工程师，企业 AI 落地进入“服务交付战”

Microsoft 成立 Frontier Company，计划投入 25 亿美元，将 6000 名行业与工程专家派驻企业客户现场，参与 AI 系统设计、部署和持续改进。这个动作说明大厂竞争已经从模型、云和软件订阅延伸到一线实施能力，企业客户购买 AI 的瓶颈也越来越多发生在流程改造、权限治理和持续运营上；管理者应把供应商驻场视为加速器，而不是替代内部能力建设。

来源：The Decoder、AI HOT

企业开始限制旗舰模型使用，AI 成本治理从财务问题变成产品架构问题

据 AI HOT 汇总，花旗、Adobe、Atlassian、亚马逊等企业正在限制员工使用高端 AI 模型，以避免按量计费导致成本失控，部分企业月度 AI 开销已出现数倍增长。对产品和研发团队来说，行动点不是简单禁用强模型，而是把任务按风险、价值、时延和可验证性分层，建立默认模型、升级条件、预算看板和审计流程；未来 Agent 产品的竞争会越来越依赖路由与成本控制，而不是只依赖单次最强输出。

来源：IT之家、AI HOT

AI 与新工具

本板块优先保留会改变研发、知识管理、运营和交互形态的工具，不收录只具话题性的泛 AI 信息。

阿里 Page Agent 开源，网页内 Agent 开始直接理解 DOM 而不是“看截图”

阿里巴巴发布 Page Agent，一个可嵌入网页的 JavaScript 客户端库，能把实时 DOM 脱水为文本映射，让 OpenAI 兼容模型用自然语言执行点击、填表等操作，并继承用户 cookies 与会话。它的价值在于把网页自动化从外部浏览器驱动推进到页面内协议层，适合客服后台、运营控制台和低代码系统尝试自然语言操作；但继承会话也意味着权限、审计和防误操作要同步设计。

来源：MarkTechPost、AI HOT

SpaceXAI 推出 Voice Agent Builder，语音 Agent 的门槛继续下降

SpaceXAI 发布 Voice Agent Builder 测试版，用无代码方式构建基于 Grok Voice 的生产级语音 Agent，支持 80 多种声音、品牌声纹克隆、知识库检索、日历工具、人工转接和护栏，并按 0.05 美元/分钟计费。客服、销售和本地服务团队可以先用咨询、预约、回访等低风险流程测试，但真正的交付重点会落在转人工规则、通话记录、数据合规和失败兜底上。

来源：xAI、juya-ai-daily

Notion 上线 HTML block，文档产品开始承接可交互 AI 输出

Notion 推出新的 HTML block，允许用户在页面内直接构建交互式 HTML 内容，并可借助 AI 或 Agent 把文档、数据库和会议记录转成图表、演示、仪表板或轻量原型。它的趋势信号很明确：AI 输出正在从纯文本回答走向 Markdown、HTML 和可交互页面，知识管理产品会越来越像轻量应用容器；团队可以把报告、需求说明和数据看板设计成可操作对象，而不是静态段落。

来源：Notion、juya-ai-daily

今日行动建议

  • 产品：梳理现有文档、后台和工作流中哪些输出可以从纯文本升级为 HTML、表格、仪表板或轻量交互页面，优先选择用户需要反复查看和修改的场景。
  • 研发：为编码 Agent 建立任务分层、模型路由和审查规则；高风险仓库不要只依赖默认模型和默认权限，先把日志、测试、PR 草稿和回退流程固化下来。
  • 运营与增长：如果业务依赖内容、数据或公开页面，被 AI 爬虫访问的策略需要重新定义，至少区分搜索可见、Agent 可用、训练禁止和付费授权四类。
  • 管理者：开始看 AI 用量和成本仪表板，明确团队级预算、旗舰模型使用条件和供应商替代方案，避免成本治理滞后于工具普及。
