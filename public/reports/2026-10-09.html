Google Cloud 发布可持续运行的 Gemini 工作智能体 ↗

Google Cloud 发布通用工作 Agent“Gemini agent”，把问答、知识工作、图像与媒体创作、编写和运行代码放进同一个 Agent 与 API。它在云端持续运行，关闭电脑后仍可执行数小时甚至数天的任务，并可通过网页、移动端、桌面端、Google Workspace、Microsoft 365 和 Slack 使用，连接企业系统及任意 MCP 服务器。

解读每个 Agent 配有独立身份和最小权限，动作写入审计日志，任务在 Agent Sandbox 中运行，Agent Gateway 负责按企业策略管控流量；底层可编排 Gemini 与 Claude，并设置项目级支出上限。这个产品把 Agent 从即时对话变成持续交付任务的云端进程，身份、权限、成本和审计不再是外围配置，而是执行链的一部分。

The Decoder / Zenity Labs · 2026-10-08 21:01

一条提示词被指可横向控制同一 AWS 账户内的 AgentCore 智能体 ↗

Zenity Labs 研究人员披露名为 AgentCorruption 的漏洞链：向一个公开的 Amazon Bedrock AgentCore 智能体发送一条提示词后，攻击者可能通过元数据服务 169.254.169.254 窃取 AWS 凭据，进而控制同账户同区域内的其他 AgentCore 智能体，读取私人对话、源代码和存储凭据，并篡改长期记忆。

解读问题涉及云凭据暴露与同账户横向权限，而不只是提示词注入本身；当多个 Agent 共用身份或网络边界时，一个公开入口可能扩大成整组智能体的控制面。
